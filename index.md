# Tabularium

The knowledge vault. An Obsidian vault, rendered to the web with Quartz and
served behind Basic Auth.

## Notes

- [[Romulus]] — Romulus, the legendary first king of Rome (753 BC).

## Простыми словами

- [[dude/index|Простыми словами]] — русские пересказы ключевых идей проекта
  для нетехнических читателей, сгруппированные по тем же категориям, что и
  английская часть хранилища. Английский текст остаётся главным; здесь
  просто более понятный пересказ, обновляемый по мере готовности показывать
  идеи стейкхолдерам.
  - [[dude/itinerarium/index|Itinerarium]] и
    [[dude/itinerarium/voice-to-lead|Voice-to-Lead]] — план приложения-схемы
    для будущей инфраструктуры и первая идея, которую оно должно нарисовать:
    превращение звонка продавца в лид.
